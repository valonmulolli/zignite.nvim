INTRODUCTION                                            *zignite-introduction*

Zignite.nvim is a blazingly fast, asynchronous code runner for Neovim,
powered by a Zig backend for maximum performance.

Features:
  • Execute code files instantly in Interactive Terminal
  • Run visual selections
  • Project-level execution with auto-detection
  • 50+ build commands across 20+ languages
  • Interactive command picker
  • Multiple output modes (float, split, vsplit, tab)
  • Beautiful animated UI with spinners
  • Syntax highlighting in output
  • Safety timeouts for infinite loops
  • Quickfix integration for errors
  • Asynchronous, non-blocking execution

==============================================================================
FEATURES                                                    *zignite-features*

FILE EXECUTION~
Run any code file with a single keypress. Supports 20+ languages including
C, C++, Rust, Zig, Go, Python, JavaScript, TypeScript, and more.

PROJECT EXECUTION~
Auto-detects project type and runs appropriate commands:
  • package.json → npm start
  • Cargo.toml → cargo run
  • go.mod → go run .
  • build.zig → zig build run
  • Makefile → make

BUILD COMMANDS~
Execute language-specific build commands:
  • Rust: build, run, test, release, check, clean
  • Zig: build, run, test, release
  • Go: build, run, test, clean, mod
  • C/C++: Make, CMake, Meson support (25+ commands)
  • JavaScript/TypeScript: npm commands
  • Python: pytest, pip

INTERACTIVE PICKER~
Visual command picker with:
  • j/k navigation
  • Arrow indicator
  • Highlighted selection
  • Quick select (1-9)
  • Bottom-right aligned

INTERACTIVE TERMINAL~
The floating window is a fully interactive terminal buffer:
  • Supports user input (stdin)
  • Renders full ANSI color codes
  • Real-time output streaming

SAFETY & ERROR HANDLING~
  • Timeouts: Automatically kills processes (e.g., infinite loops)
    if they exceed the configured time limit.
  • Quickfix: Automatically parses errors and populates the Quickfix
    list, allowing you to jump to the error quickly.

COMMANDS                                                    *zignite-commands*

                                                                    *:RunFile*
:RunFile [mode]
    Execute the current file.
    
    Arguments:
      [mode]    Optional output mode: float, split, vsplit, tab
    
    Examples: >
        :RunFile
        :RunFile split
        :RunFile vsplit
        :RunFile tab
<

                                                                    *:RunCode*
:RunCode
    Execute code in visual selection or current buffer.
    
    Usage:
      1. Select code in visual mode
      2. Run :'<,'>RunCode
    
    Example: >
        " Select lines in visual mode
        V
        :'<,'>RunCode
<

                                                                 *:RunProject*
:RunProject [mode]
    Execute project-level command (auto-detected).
    
    Arguments:
      [mode]    Optional output mode: float, split, vsplit, tab
    
    Examples: >
        :RunProject
        :RunProject tab
<

                                                                   *:RunBuild*
:RunBuild <command> [mode]
    Execute specific build command for current language.
    
    Arguments:
      <command>  Build command name (use tab completion)
      [mode]     Optional output mode: float, split, vsplit, tab
    
    Examples: >
        :RunBuild run
        :RunBuild test
        :RunBuild release
        :RunBuild cmake-run
        :RunBuild test split
<
    
    Tab completion shows available commands for current filetype.

                                                            *:RunBuildSelect*
:RunBuildSelect [mode]
    Show interactive picker to select build command.
    
    Arguments:
      [mode]    Optional output mode: float, split, vsplit, tab
    
    Navigation:
      j, ↓      Move down
      k, ↑      Move up
      Enter     Select command
      1-9       Quick select
      Esc, q    Cancel
    
    Examples: >
        :RunBuildSelect
        :RunBuildSelect split
<

                                                                  *:RunClose*
:RunClose
    Close the output window.

                                                                  *:StopCode*
:StopCode
    Stop the currently running process.

KEYMAPS                                                      *zignite-keymaps*

Default keymaps:

  <leader>r       Run current file                          *<leader>r*
  <leader>rb      Show build command picker                 *<leader>rb*
  <leader>rp      Run project                               *<leader>rp*
  <leader>rq      Close output window                       *<leader>rq*
  <leader>rt      Run file in new tab                       *<leader>rt*
  <leader>rv      Run file in vertical split                *<leader>rv*
  <leader>rh      Run file in horizontal split              *<leader>rh*

All keymaps are customizable via configuration.

CONFIGURATION                                          *zignite-configuration*

Basic setup: >lua
    require("zignite.config").setup({
        mode = "float",  -- Default output mode
        timeout = nil,   -- Timeout in ms (e.g. 5000). nil = disabled.
        
        keymaps = {
            { "n", "<leader>r", ":RunFile<CR>", { desc = "Run file" } },
            { "n", "<leader>rb", ":RunBuildSelect<CR>", { desc = "Build picker" } },
        },
    })
<

RUNNERS~
                                                          *zignite-config-runners*
Customize file execution commands: >lua
    runners = {
        python = "python3 -u $file",
        javascript = "node $file",
        c = {
            cmd = {
                "cd $dir",
                "gcc $fileName -o /tmp/$fileNameWithoutExt",
                "/tmp/$fileNameWithoutExt",
            },
            cleanup_command = "rm /tmp/$fileNameWithoutExt"
        },
    }
<

Available variables:
  $file                 Full absolute path
  $fileName             Filename with extension
  $fileNameWithoutExt   Filename without extension
  $dir                  Directory path
  $fileExt              File extension
  $dirName              Directory name

BUILD COMMANDS~
                                                   *zignite-config-build-commands*
Customize build commands: >lua
    build_commands = {
        rust = {
            build = "cargo build",
            run = "cargo run",
            test = "cargo test",
            bench = "cargo bench",  -- Add custom commands
        },
    }
<

UI CONFIGURATION~
                                                            *zignite-config-ui*
Customize floating window: >lua
    float = {
        border = "rounded",
        height = 0.8,
        width = 0.8,
        x = 0.5,  -- Center horizontally
        y = 0.5,  -- Center vertically
    }
<

Customize terminal: >lua
    term = {
        position = "bot",  -- bot, top, left, right
        size = 15,
        focus = true,
    }
<

Customize animations: >lua
    spinner = "dots",  -- dots, line, bar, arrows, etc.
    spinner_speed = 80,
    enable_animations = true,
<

QUICKFIX CONFIGURATION~
                                                      *zignite-config-quickfix*
Configure quickfix generation on failed runs: >lua
    quickfix = {
        enabled = true,
        processor = "auto",         -- auto | lua | zig
        zig_min_lines = 300,        -- auto threshold for zig processor
        max_lines = 1000,
        max_bytes = 262144,
        strip_ansi = true,
        strip_ansi_max_lines = 400,
        parse_diagnostics = true,   -- zig processor canonicalization
        async_strip = true,         -- lua processor fallback
        strip_chunk_size = 200,
    }
<

BUILD COMMANDS                                        *zignite-build-commands*

RUST (CARGO)~
  build             cargo build
  run               cargo run
  test              cargo test
  release           cargo build --release
  release-run       cargo run --release
  check             cargo check
  clean             cargo clean

ZIG~
  build             zig build
  run               zig build run
  test              zig build test
  release           zig build -Doptimize=ReleaseFast
  release-run       zig build run -Doptimize=ReleaseFast

GO~
  build             go build
  run               go run .
  test              go test ./...
  clean             go clean
  mod               go mod tidy

C/C++ (MAKE)~
  build             make
  run               make run
  clean             make clean
  test              make test
  install           make install
  debug             make debug

C/C++ (CMAKE)~
  cmake-config      cmake -B build
  cmake-build       cmake --build build
  cmake-run         cmake --build build && ./build/main
  cmake-clean       rm -rf build
  cmake-debug       cmake -B build -DCMAKE_BUILD_TYPE=Debug
  cmake-release     cmake -B build -DCMAKE_BUILD_TYPE=Release
  cmake-test        cd build && ctest

C/C++ (MESON)~
  meson-setup       meson setup build
  meson-build       meson compile -C build
  meson-run         meson compile -C build && ./build/main
  meson-clean       rm -rf build
  meson-test        meson test -C build

JAVASCRIPT/TYPESCRIPT (NPM)~
  start             npm start
  dev               npm run dev
  build             npm run build
  test              npm test
  install           npm install

PYTHON~
  run               python -m main
  test              pytest
  install           pip install -r requirements.txt

TROUBLESHOOTING                                      *zignite-troubleshooting*

PLUGIN NOT LOADING~
Check if commands exist: >
    :echo exists(':RunFile')
<
Should return 2. If not, check your plugin manager configuration.

KEYMAPS NOT WORKING~
Check keymap: >
    :nmap <leader>r
<
Should show the mapping. If not, check for conflicts.

BUILD COMMANDS NOT AVAILABLE~
Check if build commands are configured for your filetype: >
    :lua print(vim.inspect(require("zignite.config").options.build_commands))
<

ZIG BACKEND NOT FOUND~
Build the Zig backend: >
    cd /path/to/zignite.nvim-v0/zig
    zig build
<
